# GitHub upload instructions

1. Visit https://github.com/new
2. Repository name: `Two-Button-Latching-EStop-Arduino-Wokwi`
3. Description: `Arduino UNO two-button START/STOP latching control with stop-priority logic, LED status, serial monitoring and Wokwi simulation.`
4. Select Public or Private. Do not initialize with a README because one is included. Create repository.
5. Extract the ZIP archive locally.
6. Select all **contents** of the project folder (including folders), not the ZIP archive itself.
7. On the new GitHub repository, choose Add file > Upload files. Drag and drop the selected contents.
8. Commit message: `Initial commit - Two Button Latching Stop Wokwi simulation`
9. Click Commit changes. `README.md` displays on your GitHub homepage.

To view the Wokwi project, create a new Arduino Uno project at https://wokwi.com/projects/new/arduino-uno and copy `sketch.ino` and `diagram.json` into the matching Wokwi editor tabs.
